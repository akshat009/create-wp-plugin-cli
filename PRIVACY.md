# Privacy policy

Applies to the create-wp-plugin-cli npm package and the `create-wp-plugin` Claude Code plugin in this repository.

## What we collect

Nothing. Neither the CLI nor the Claude Code plugin collects, stores or sends personal data, usage data or telemetry to the author or to any service run by the author.

## What runs on your machine

- The CLI writes the generated plugin files to the folder you choose, on your own computer.
- Details you pass in, such as the plugin name, author name, email or URL, go only into those generated files.
- The `scaffold` skill asks Claude Code to run `npx`, `composer` and, for some modules, `npm`. Those tools download packages from the npm registry and Packagist under those services' own privacy policies. No data about you or your project is sent to the author.
